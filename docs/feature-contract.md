# 固定功能契约 · v1

用户确认的评审界面是稳定能力，不随产品页面每轮重新实现。

| 能力 | 固定行为 |
| --- | --- |
| 顶部工具栏 | 问题与批注、设计工具、项目资料分组；随窗口宽度自动换行 |
| 机型切换 | 上方按钮真实切换设计图；折叠和展开是独立形态；按原图比例展示 |
| 三栏看稿 | 左侧页面目录，中间原图及留白，右侧画图与评论；窄屏可重排 |
| 逐页文档 | 每条设计稿右侧上下叠放「产」「测」，整体与页面按钮等高；在新标签页打开对应版本的独立文档，分别定位产品说明和测试用例，原评审页保持原位置 |
| 画布 | 留白同样可画；坐标相对原图，可小于0或大于1；不把批注烘焙进原图 |
| 标记 | 画笔、矩形框、箭头、评论位置；颜色、粗细、撤销、删除。默认直接浏览，点击/拖动已有标记选择与移动，不单设浏览/选择按钮；画完、再次点击工具或 Esc 结束绘制 |
| 编辑键盘 | 选中标记可Delete/Backspace删除；输入框中这些键只编辑文字 |
| 方向键导航 | ↑↓ 按左侧目录顺序切换页面，←→ 按顶部顺序切换机型和折叠形态；到列表边界停止；输入文字和打开设置时暂停 |
| 评论 | 位置或整页评论；更新保留问题号；刷新后恢复；草稿按页面、机型与标记隔离，切换后可继续评论和确认其他页面，返回时恢复草稿 |
| 附图 | 文件上传、原生粘贴、macOS Ctrl+V兼容、拖入；预览与移除；随评论保存 |
| 存储 | 本机文件、事务日志、幂等操作、失败重试、修改/移动/撤回历史 |
| 上下文 | 项目、版本、页面、机型独立；记录源图SHA256，旧坐标不画在新版本上 |
| 问题交接 | 复制/下载清单或CLI导出；包含问题号、版本、页面、设备、坐标、源图哈希和附图路径 |
| 逐项处理 | 对话里的agent先读反馈，逐问题修改，写处理说明与证据；未解决项不随发版自动关闭 |
| 修订 | 每轮新ID/新目录，历史可切回；检查资源齐全后切换当前版本 |
| 看稿更新 | 地址不变、原标签页更新，不开新标签页；默认自动检测；未保存内容先保护 |

设备集合、分组、图片和扩展链接可配置；“可配置”不表示可以去掉上述固定工具。默认设备数据在 docs/device-presets.json 和初始化项目 manifest 中保持一致。

逐页文档放在各版本根目录的 `page-docs.json`。用 `pages` 按 `coverage.json` 的页面 ID 映射。每页支持 `product`（功能摘要）、`test`（补充测试说明）、`sections`（含 `title` 和 `items`）与 `cases`（含 `title`、`setup`、`steps` 和 `expected`）。正文、条目和用例各字段使用纯文本，列表字段使用字符串数组。可加顶层 `status` 标明评审稿或验证状态。文档页提供对应机型设计稿预览，未关联内容时明确提示。

文件大小限制：单张附图8 MB、最多4000万像素，每条评论最多8张；PNG/JPG/WebP。评论最多6000字。幂等请求记录最近5000个操作。服务仅在回环地址监听，读文件限定在显式项目根/资源根内，不提供目录遍历。

历史版本允许查看和补充批注；来源版本不会改成当前版本。harness 不能通过本地校验得知设计图的产品风格已经获得用户认可。

## 交接待处理问题

从工具栏复制或下载待处理问题，即可把已保存的反馈交给来源对话。项目可通过 `rig.json` 的 `codex_source` 记录来源对话的 `thread_id`、`title` 和 `cwd`，相对目录以 `rig.json` 所在目录为准。本机接口 `/api/codex-work` 继续兼容已有调用方。

交接保留批注的原问题号、页面及机型。Codex 结合用户补充和当前设计稿，对照同一功能的各机型、折叠形态及相关状态，判断影响范围，修复所有受影响的变体，并在原问题下记录覆盖范围与验证结果。

## Lottie 固定能力

- 本地实际播放器：SVG与Canvas可切换；ready后才启用播放。
- 播放、暂停、重播、帧时间轴、速度、显式循环；默认不强制循环。
- 起点生成、JSON编辑/导入、结构检查、JSON及生成器导出；自定义生成器留在项目。
- 每实例销毁、异步加载代次隔离、尺寸变化；错误不显示成已加载。
- 保留构造器、检查器及播放器版本；结构检查与实际回放分别记录，Web结果不冒充原生验收。

框架层由启动及资源完整性校验保护；普通设计对话只更新项目内容，修改固定工具必须明确进入 harness 维护任务。

已完成问题收到新的文字/附图补充时，保留问题号并重新进入待处理；再次保存相同内容不会重复开启。
## 页面检查状态

- 页面导航按全部机型计算确认百分比，用绿色填充。待修改标红、修改后待复查标黄、通过标绿，红色优先于黄色；其余机型的确认仍计数。左侧总进度覆盖当前版本的所有页面 × 机型，全部组合确认才显示 100%。
- 右侧固定提供「检查确认」，再次点击已确认按钮可撤回。当前页面已确认的机型按钮显示绿色；撤回立即更新进度，无批注页面也可确认，状态刷新恢复。
- 「全部确认」并排位于「检查确认」右侧，一次确认当前页面的全部机型。该页面显示 100%，所有机型按钮变绿，右侧按钮切换为「全部取消」。点击「全部取消」撤回该页面所有机型的确认，已有待修改或待复查状态重新显示。任一机型的稿件或反馈已变化时整批拒绝，可在重新检查后重试。
- 新版、改版和待复查的页面都可以批量确认。单机型可以确认时，批量按钮也可操作；尚在读取的批量状态会在提交前补齐。保存成功后直接用返回结果更新页面、机型和总进度。
- 确认请求失败或超时后主动重新读取已保存状态，恢复可用的确认按钮。
- 当前页读取和写入只核对该页，先更新按钮及该页进度。整个目录的统计由独立请求刷新。
- `⌘B` 默认切换当前页面当前机型的确认，`⌘⇧B` 默认切换当前页全部机型的确认。两个按钮显示当前快捷键。「快捷键设置」可分别录入不同的组合或恢复默认，设置保存在当前浏览器。编辑文字或打开设置时暂停触发。
- 同内容的新版本保留确认；图片、关联动画或反馈变化使确认失效。内容曾变化后即使恢复旧图也需要重查。
- 确认记录持久保留，历史版本独立查看；提交时内容或反馈已变更应拒绝过期确认。
- resolve 记录修复结果但不代用户验收。用户确认不等同于自动关闭问题。

## 公共元素集

- 固定提供目录、tokens、命名变体、状态预览、搜索、规范下载与项目复用渲染器。
- 项目按设计版本保存元素集；公共返回/确认等复用同一 ID。可通过 stack 组合已注册组件。
- 发布校验未知引用、重复 ID、无效 tokens、循环组合；可要求全部页面声明引用。
- 旧项目缺少规范时明确显示通用示例，不自动替换产品设计。
- 规范变化使旧的人工确认失效；agent 交接包含元素集路径、版本和复用约定。
- PNG 的视觉一致性仍需实际渲染验收，组件引用清单不等同于像素验证。
