Tailorbird Rig 0.2.0。公开工程使用产品无关的合成夹具；Lottie 播放器锁定 5.12.2。

- Lottie SVG 和 Canvas 实际完成整段播放；覆盖时间轴、路径动画生成、生成器下载及无效 JSON 提示。
- wheel 构建、解包后的 CLI 与框架校验；核对合成示例图片、本地播放器及许可证进入发行包。
